# Improvement Registry

- Date: 2026-11-01 (UTC)
- Status: Current; approved by the 2026-11-01 workflow reset
- Contract: [`docs/workflows/run-contract.md`](../workflows/run-contract.md)

This directory is the committed record of improvement runs. The run folders
themselves live in the local workspace at `data/improvement/<YYYY-MM-DD>/<run-id>/`;
this directory holds the durable index, the baseline registry, the invalidation
tombstones, and the templates a run record follows.

## Contents

| File | Holds | Generated? |
|---|---|---|
| [`index.md`](index.md) | Committed snapshot of the generated run index | Yes; copy from `data/improvement/index.md`, never edit by hand |
| [`baselines.md`](baselines.md) | The accepted model, strategy, and portfolio baselines | No; updated by the reviewer and the human |
| [`INVALIDATIONS.md`](INVALIDATIONS.md) | Append-only tombstones for removed or superseded evidence | No; append only |
| `README.md` | This guide and the run record template | No |

The working files under `data/improvement/` (`index.json`, `index.md`) are
generated by `tools/improvement/index.py`. When a working copy and a committed
file disagree, the committed file wins and the working copy is regenerated.

## Run record

A run folder contains:

```text
data/improvement/<YYYY-MM-DD>/<run-id>/
  manifest.json
  config/
    sources.json
    <run config and sibling JSON files>
  artifacts/
    <shell bundles>
    evidence.json
  results.json
  review.md
  decision.md
```

`manifest.json` is staged before the run and never rewritten. `run.py` creates
the canonical run folder, copies the manifest and config, runs the shell, and
writes `results.json`. `evidence.py` writes `artifacts/evidence.json`.
`review.md` and `decision.md` use the templates below. The index is regenerated
after the decision, not hand-edited.

## Rules

- A run without a manifest is not evidence.
- A result without `review.md` is not reviewed; a run without `decision.md` is not
  decided.
- Only the human accepts a baseline. An agent may recommend, never accept.
- The index is generated; a hand edit is overwritten and is a defect.
- `INVALIDATIONS.md` is append-only. Never delete a row, even after the artifacts
  are removed.
- No pre-reset experiment or audit record is imported as a run. The reset has no
  backwards-compatibility layer.
- A baseline is not a live-trading approval; it is the comparison point for the
  next tier.
