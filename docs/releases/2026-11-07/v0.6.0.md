## Scope

This release makes the workflow documentation and operating model match the
implemented S3 command surface.

Included:

- Workflow index, tier runbooks, engineering lifecycle workflows, templates, and
  record map.
- Grouped-release changelog, release index, and immutable release-tag rule.
- Current status reconciliation across `AGENTS.md`, `README.md`, `docs/README.md`,
  architecture, policy/strategy, model, registry, roles, and improvement docs.
- Workflow, changelog, release, and partition checkers, with tests and CI.
- Current improvement run adapter, manifest v2, and evidence extraction.
- Issue and PR templates and the workflow lab tutorial.
- Canonical partition instruments with aliases for the historical research
  configs.

Excluded:

- Model, strategy, execution, portfolio, or policy behavior changes.
- Validation partition access.
- Destructive legacy data cleanup.
- A new model, strategy, or portfolio baseline.

## Risks

- The run-store adapter is verified on shell fixtures, not on a production data
  pack. The first tiered run needs a real manifest and data version.
- The S3 command surface is implemented, but no tiered improvement run has used
  it yet; no strategy or portfolio baseline exists.
- Historical local data directories remain; their cleanup is a separate,
  destructive change.
- The S3 human acceptance remains separate from this release.

## Rollback

The previous release is `v0.5.0`. This release changes documentation, workflow
contracts, tooling, and tests; it does not change model formulas, event
definitions, strategy rules, execution mechanics, portfolio accounting, or
policy thresholds. A rollback is a checkout of `v0.5.0` plus the documented
recovery of the release records.
