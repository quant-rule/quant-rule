## Scope

The release removes the desktop distribution and the Python tooling, and makes
the release path build once and promote the same binary artifact.

- Removed the Tauri shell, supervisor, AppImage, NSIS, every installer, the
  desktop release job, and the embedded SQLite/CAS/in-process-queue profile.
- `main` publishes `release-binaries-<sha>`; the release downloads that exact
  artifact and assembles the thin runtime image from it.
- The browser is the only GUI; the headless `quantrule` CLI remains the agent
  client. Windows and Linux are supported; macOS is unsupported.
- Zero Python: 26 Rust checkers, and no interpreter in the gate, CI, release,
  composed tier, multi-host harness, or image.
- Retired the historical Python checker, data, research, and improvement stacks;
  current commands are `qr-governance check`, `qr-governance improvement`, and
  `qr-governance research`.
- No model, strategy, execution, portfolio, or server behavior changed.

## Risks and rollback

- A user who relied on the desktop app or an installer has no replacement in
  this release; the browser client and source-built CLI are the supported paths.
- The retired Python tools are recoverable from Git history only. The committed
  configs, run records, source CSVs, and release notes remain the audit trail.
- Rollback is the previous published image, `v1.4.2`.
- No schema migration or data rewrite is introduced by this release.
