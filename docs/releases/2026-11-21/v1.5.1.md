## Scope

`v1.5.1` carries the same feature scope as `v1.5.0` and fixes the release gate
that stopped it:

- the v1.5.0 tag is retained, but its release workflow failed in the Windows CLI
  job with `os error 10053`;
- the in-process test fixture keeps listening after a vanished peer and closes
  each response stream cleanly, so the Windows job runs the unchanged test set;
- no product, model, strategy, execution, portfolio, or server behavior changed.

The `v1.5.0` feature scope remains: desktop distribution retired, build-once
release artifact promoted into the thin image, browser and headless CLI clients,
and zero Python in the repository, gate, CI, release, composed tier, multi-host
harness, and image.
