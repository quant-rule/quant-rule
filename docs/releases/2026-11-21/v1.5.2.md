## Scope

`v1.5.2` carries the same feature scope as `v1.5.0` and completes the release
gate recovery:

- the in-process fixture server makes each accepted socket blocking before the
  first read; on Windows an accepted socket could inherit the listener's
  non-blocking flag, so the first read returned no data and the client aborted
  with `os error 10053`;
- `v1.5.0` and `v1.5.1` are withdrawn; their tags are retained and their notes
  record the supersession;
- no product, model, strategy, execution, portfolio, or server behavior changed.

The `v1.5.0` feature scope remains: desktop distribution retired, build-once
release artifact promoted into the thin image, browser and headless CLI clients,
and zero Python in the repository, gate, CI, release, composed tier, multi-host
harness, and image.
