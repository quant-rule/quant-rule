## What this release is

MVP v1 makes a config-driven, reproducible backtest reachable from the shell.
One `run.json` names six engine configs; one `backtest` command runs the data,
model, strategy, execution, and portfolio engines in a single deterministic pass
and writes five report bundles. The market-analysis commands of the earlier
slices are unchanged, and `market-report` keeps its four-artifact contract.

## Commands

| Command | Output |
|---|---|
| `backtest --config <run.json> [--out <dir>] [--json]` | Five bundles under `<out>/<engine>/` and a summary envelope with `--json` |
| `report model\|strategy\|execution\|portfolio\|analytical --config <run.json> [--out <dir>] [--json]` | One bundle, under `<out>/<engine>/` |
| `market-report <csv> --data-version <id> --out <dir>` | Legacy four-artifact market report; byte-identical to the model bundle |
| `strategy-run <csv> --strategy axis-agreement --data-version <id>` | Strategy entries and exits; no fills, positions, equity, or P&L |
| `candles`, `candles-tolerant`, `timeframes`, `market-state`, `market-dashboard`, `market-chart`, `axis`, `events`, `legs`, `model-series`, `research`, `store`, `db`, `fetch`, `help` | Unchanged from earlier slices |

`help` lists every command with its arguments. A bundle is available if and only
if its `report.json` exists; `backtest` refuses a non-empty run root and removes
what it wrote when a run fails.

## Configuration

| File | Contents |
|---|---|
| `run.json` | Run name, the six file names, output root |
| `data.json` | Source CSV, data version, UTC period, the fixed 1m/5m/15m/1h ladder, `max_candles` |
| `model.json` | Structure scale (`major` or `minor`) |
| `strategy.json` | `axis-agreement` timeframe and the long/short thresholds |
| `execution.json` | Fill timeframe, order type, stop and target ATR multiples, tie break, fee rate, slippage, zero-volume and end-of-data policy |
| `portfolio.json` | Cash, currency, sizing, leverage, position limit, commission, funding, drawdown limit and action, mark policy |
| `analytics.json` | Analytical report scale, timeframe subset, relations switch |

The loader validates the whole run before a candle is read or a byte is written.
A rejection names the file and JSON path, never an absolute path. The contract is
[`docs/config/2026-10-28/per-engine-config.md`](../../config/2026-10-28/per-engine-config.md),
and the example run is `config/examples/solusd-2025/`.

## Reports

| Bundle | Artifacts |
|---|---|
| `model/` | `summary.txt`, `report.json`, `price-axes.png`, `events.png`, `provenance.json` |
| `strategy/` | `summary.txt`, `report.json`, `decisions.csv`, `price-decisions.png`, `provenance.json` |
| `execution/` | `summary.txt`, `report.json`, `orders.csv`, `fills.csv`, `rejections.csv`, `price-fills.png`, `provenance.json` |
| `portfolio/` | `summary.txt`, `report.json`, `trades.csv`, `equity.csv`, `equity.png`, `drawdown.png`, `provenance.json` |
| `analytical/` | `summary.txt`, `report.json`, `axes.csv`, `relations.csv`, `provenance.json` |

Each bundle stays on its own side of the boundary: strategy publishes no fill or
P&L, execution publishes no capital, portfolio publishes no model label, and the
analytical report publishes neither strategy nor execution. `provenance.json`
records the data version, the requested and actual periods, the config file
names, the resolved values, and the artifact list.

## Accounting rules

| Rule | Behavior |
|---|---|
| Sizing | A decision-bar close and the current equity produce a quantity, floored to `quantity_step` |
| Fill | A market order fills at the next bar's open, adjusted by slippage |
| Commission | `rate × total portfolio equity before the operation`, on entry and exit |
| Funding | At an aligned UTC boundary, before the bar's fills; a positive rate means a long pays and a short receives |
| Drawdown halt | Latches at or above the limit, records one risk event, blocks new entries, never liquidates |
| End of data | An open position stays open and is marked at the last close |
| Mark | `equity = cash + position_value` at each strategy bar close, so `final_equity = initial_cash + net_pnl` |

## Compatibility

- `market-report` retains its four artifacts and its byte output.
- `strategy-run` retains its NDJSON shape and still publishes no fills or P&L.
- The existing analysis, chart, store, research, and fetch commands are
  unchanged.
- The workspace version moves from `0.1.0` to `0.2.0`; `0.1.0` was a version
  marker, not a released tag. `v0.2.0` is the first tag in the repository.
