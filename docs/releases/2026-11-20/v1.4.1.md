## Scope

The v1.4.0 recovery release. It fixes the defects that stopped publication:

- the simulation Postgres list queries now return `archived_at` as RFC3339 text and exclude archived runs from the active list, matching the shared row type and the SQLite store;
- the desktop shell `SHELL_VERSION` moves to `1.4.1`, and the version-boundary test compares the manifests instead of a hardcoded literal.

It also bumps the workspace, web, desktop, and supervisor versions and updates the model-object oracle for the version string.

## Risks and rollback
