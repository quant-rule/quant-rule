## Scope

The v1.4.2 recovery carries the v1.4.1 fixes and closes the failure that stopped
v1.4.1 publication:

- the packaged desktop parity smoke compares against the current canonical
  digest `sha256:a0372f02…`, so the packaged Linux and Windows profiles match the
  server profile;
- the simulation Postgres list queries return `archived_at` as RFC3339 text and
  exclude archived runs from the active list, matching the SQLite store;
- the desktop shell `SHELL_VERSION` is `1.4.2`, and the version-boundary test
  compares the manifests instead of a hardcoded literal.

It also bumps the workspace, web, desktop, and supervisor versions and updates
the model-object oracle for the version string.
