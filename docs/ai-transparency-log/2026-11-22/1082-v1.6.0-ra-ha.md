## Learning and corrections

- The first issue-creation script used `gh issue create --json`, which is not
  supported by the installed CLI. The script was corrected to parse the printed
  issue URL and later to use the REST endpoint.
- The project board API rate-limited during bulk issue creation. Issues were
  created through REST; board field backfill remains a follow-up.
- The earlier conversation used `v2.0.0` and a placeholder URL. The human corrected
  both: the final product version is `v1.6.0`, the descriptor stays `v3`, and
  the only public name is `https://quantrule.dev`.
- The model artifact was missing from an early four-object RA table. It is now
  explicit as the upstream fifth artifact.
- Live-trading readiness was rejected as out of scope; the platform is a
  research system that never trades.
