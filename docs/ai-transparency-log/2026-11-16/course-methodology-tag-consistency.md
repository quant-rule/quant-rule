## Learning

- A tag-map line belongs in the source at the top of each checkpoint so the
  generated PDF carries it automatically; repeating the full history in every
  checkpoint caused the drift the review found.
- The server platform (`v0.9.0`), the desktop package (`v1.0.0`), and the
  alignment releases (`v1.1.0`, `v1.2.0`) are separate identities; "previous
  release" in a rollback means `v1.1.0`, not the server baseline.
