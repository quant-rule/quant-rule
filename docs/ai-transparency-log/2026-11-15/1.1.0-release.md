### The one golden this changed

`crates/quantrule-model-service/tests/model.rs` compares the stored model object
against a SHA-256 captured from the coupled gateway route. The object carries the
compiled product version in `.model_version`, so `1.0.0` to `1.1.0` changes it.
The oracle was regenerated deliberately, and the delta was proven before the
constant changed: a temporary dump of the stored object at `1.0.0` reproduced the
recorded baseline `sha256:dcb9bed7…` and 66,022 bytes; the same dump at `1.1.0`
is 66,022 bytes with `sha256:d3ed28f8…`; `cmp -l` reports two differing bytes and
a semantic JSON diff reports one path, `.model_version` (`1.0.0` → `1.1.0`). No
reading, event, report, or canonical artifact value changed.

## Learning

- The checked-in verify-mini pair no longer creates a run on a stack whose
  volumes already hold it; `created=false` replays the existing run and would not
  exercise the new tree. Changing the run name in a temporary copy forces a new
  config hash and run identity, and both fresh runs still print the expected
  digest.
- `tools/check_legacy.py` bans `AppImage` as a retired architecture term in
  current docs, while release notes and the desktop README are outside that
  scan. The status row says "Linux and Windows installers"; the artifact names
  stay in the release note and the desktop README.
- `apps/web/bun.lock` records the workspace name and dependency graph, not the
  package version, so the version bump has no lockfile delta there. The desktop
  lockfiles do record their package version and both moved.
