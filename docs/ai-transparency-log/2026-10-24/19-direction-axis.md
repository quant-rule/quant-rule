## Entry: read-only review and corrections

- **Date and tool:** 2026-10-24 (UTC). A separate read-only review agent (same model family, independent session) reviewed the diff against the contract, issue #19, and the plan. It did not modify files or run git write commands.
- **Intent and boundary:** Check the formula, null/zero discipline, percentile, counters, causality, determinism, no-double-count behavior, fixture independence, and test coverage.
- **Findings and corrections:**
  - The plan classified a non-finite ATR as reason 1 while the code and test used reason 3. The plan was corrected to reason 3 for a non-finite, zero, or negative ATR; a missing EMA or ATR remains reason 1.
  - The formula test did not distinguish per-leg clamping from clamping only the average. A case with one leg clamped and the other not was added; it expects 0.75.
  - The unit test's pivot mutation was a no-op because both readings already had an empty pivot series. The changed readings now carry a non-empty pivot series.
  - The golden parser parsed integer codes through `f64` and cast them. It now parses optional integers exactly, and the `replace_candle` helper is safe for a negative move.
  - The README said indicators and the four-axis model were not implemented, which was stale for the model crate. The sentence now says the shell does not expose them yet.
  - The golden fixture's valid bars are all state -1 with no change. This is recorded as a coverage limitation rather than hidden; unit tests cover the other state paths.
- **Verification and evidence:** After the corrections, `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` (385 passed), and `RUSTDOCFLAGS="-D warnings" cargo doc --no-deps` are clean. The reviewer independently recomputed the fixture from the CSV candles and reported a maximum absolute difference of `1.08e-14` with zero mismatches. A timestamp-independence test was added after the review to show that Direction consumes bar order, not wall-clock spacing.
- **Learning:** The strongest review finding was a documentation/code mismatch, not a numeric defect. The independent recomputation is a useful check that the checked-in fixture is self-consistent, but it cannot prove the fixture was generated independently; the plan and this log therefore state the provenance rather than treating the fixture as self-authenticating.
