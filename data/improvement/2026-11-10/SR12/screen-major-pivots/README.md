# Invalid Major-Pivot Screen

These files are the H1 screen at major pivots (source 8). The model publishes the
events, but the compiled strategy registry exposes only each event's primary
source, so source 8 is not readable by the event-composite engine. The screen is
descriptive only and is not evidence for SR12. The valid H1 screen uses VWAP
(source 19) under `../screen/`.
