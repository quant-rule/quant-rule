# Notes

Human-authored material, not generated output.

- Protocols, role notes, and review notes used by `lab summary --notes`.
- Name files by role and purpose, for example `researcher-protocol.md`.
- A note is not evidence of a result; it records what was intended or observed.
- Keep a note beside the lab it describes, and delete both together.
- Never place credentials, account identifiers, or vendor keys here.
