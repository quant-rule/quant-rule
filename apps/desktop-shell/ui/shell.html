Gateway

The shell is a window. Every measurement and every run comes from this gateway; nothing is computed or stored on this machine.

Starting…

The active profile is chosen in the client and sent as X-QuantRule-Profile. The web client remembers it with the gateway session; the shell adds no profile storage.

Update

Artifacts are unsigned. Windows shows a SmartScreen warning; the Linux AppImage carries no signature. Download the release for this platform and replace the installed copy.
