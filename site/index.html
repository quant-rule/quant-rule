Install

AppImage

chmod +x QuantRule_0.9.0_amd64.AppImage
./QuantRule_0.9.0_amd64.AppImage

If your system has no FUSE, run APPIMAGE_EXTRACT_AND_RUN=1 ./QuantRule_0.9.0_amd64.AppImage.

Debian / Ubuntu

sudo apt install ./QuantRule_0.9.0_amd64.deb
quantrule-desktop

The package depends on WebKitGTK 4.1 and GTK 3.

Verify

Download checksums.txt next to the artifacts, then run: 

sha256sum -c checksums.txt

Every release publishes the checksums beside the binaries. The download page and the checksum file are generated from the same build.

Requirements

Runtime

  • Linux x86_64
  • GTK 3 and WebKitGTK 4.1
  • libsoup 3
  • Ubuntu 24.04+ or Fedora 40+

Boundary

  • No account, login, or subscription
  • No cloud compute or cloud data store
  • No engine network calls
  • Candles, configs, and memory stay local

What this build does

Included

  • Workspace and dataset inspection
  • Run validation and model run
  • Local SQLite research memory
  • Export, import, backup, and restore

CLI for now

  • Backtest and strategy runs
  • Execution and portfolio replay
  • Qualification and analytics
